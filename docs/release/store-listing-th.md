# Cadentra — ข้อมูลหน้าร้านภาษาไทย

## ชื่อแอป

Cadentra

## คำอธิบายสั้น

วางแผนงาน สร้างนิสัย และโฟกัสอย่างสม่ำเสมอในจังหวะของคุณ

## คำอธิบายฉบับเต็ม

Cadentra ช่วยรวมตาราง งาน เป้าหมาย นิสัย และช่วงโฟกัสไว้ในที่เดียว เพื่อให้คุณเห็นสิ่งสำคัญของวันนี้และกลับมาเริ่มใหม่ได้ง่ายเมื่อแผนเปลี่ยน

- วางแผนวันและสัปดาห์ด้วยปฏิทินและ Time Blocking
- จัดการงาน งานย่อย งานประจำ และเป้าหมายระยะยาว
- ติดตามนิสัยหลายรูปแบบโดยไม่ลงโทษวันที่พลาด
- ใช้ Focus Timer พร้อมบันทึกสิ่งรบกวนและเวลาที่ทำจริง
- ทบทวนความก้าวหน้ารายวันและรายสัปดาห์
- ใช้ AI Coach ผ่านขั้นตอนเสนอ Preview และยืนยันก่อนบันทึกเสมอ
- เชื่อม Google Calendar และ Health Connect แบบเลือกเปิดได้
- ดูข้อมูลล่าสุดและบันทึกการเปลี่ยนแปลงชั่วคราวเมื่อออฟไลน์

ข้อมูลส่วนตัวของแต่ละบัญชีถูกแยกด้วย Row Level Security ข้อมูล Health Connect ที่ส่งขึ้นคลาวด์มีเฉพาะยอดรวมรายวันของก้าวเดิน การนอน และการออกกำลังกาย คุณควบคุมการเชื่อมต่อ การส่งออก และการลบบัญชีได้จาก Settings

Cadentra ไม่มีโฆษณา ไม่มีการแข่งขันกับผู้อื่น และออกแบบมาเพื่อช่วยให้คุณสม่ำเสมออย่างใจดีกับตัวเอง
