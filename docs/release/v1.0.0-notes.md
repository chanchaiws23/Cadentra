# Cadentra 1.0.0 release notes

Cadentra V1 brings personal planning, recurring tasks, goals and milestones, flexible habits, focus sessions, daily reflection, weekly review, rewards, exports, offline queuing, Google Calendar sync, optional Health Connect daily aggregates, push notifications, and confirmation-gated AI Coach proposals to Android and the web.

The first closed beta focuses on data isolation, reliable offline recovery, timezone correctness, notification delivery after Android lifecycle changes, and ensuring AI never changes a schedule before explicit confirmation.
