# Release documentation

V1 is prepared for Android 16 / API level 36. Google Play requires new apps and updates to target API 36 from 31 August 2026: <https://developer.android.com/google/play/requirements/target-sdk>.

The store feature graphic and screenshot rules were checked against the Play Console preview-asset documentation: <https://support.google.com/googleplay/android-developer/answer/9866151>. New Play apps ship as Android App Bundles and use an upload key with Play App Signing: <https://developer.android.com/studio/publish/app-signing>.

Start with `release-checklist.md`, reconcile `play-data-safety.md` with the production configuration, then use the localized listing drafts and the assets under `assets/store`.
