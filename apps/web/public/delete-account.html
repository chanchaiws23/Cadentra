ลบบัญชีและข้อมูล

คุณลบบัญชี Cadentra ได้เองจากแอปโดยไม่ต้องติดต่อผู้ดูแล

1. เข้าสู่ระบบ แล้วเปิด Settings / ตั้งค่า
2. เลื่อนไปที่ส่วนข้อมูลและบัญชี แล้วเลือก ลบบัญชี
3. อ่านรายการข้อมูลที่จะถูกลบและยืนยันอีกครั้ง

กระบวนการจะลบข้อมูลโปรไฟล์ งาน เป้าหมาย นิสัย Reflection Focus session คะแนน ข้อเสนอ AI การเชื่อมต่อปฏิทิน OAuth token push registration ยอดรวมสุขภาพ และไฟล์ที่ผูกกับบัญชี การเปลี่ยนแปลงนี้ย้อนกลับไม่ได้ จึงควรส่งออกข้อมูลก่อนหากต้องการเก็บสำเนา

หากเข้าแอปไม่ได้

เปิดคำขอผ่าน Cadentra support tracker โดยระบุว่าเป็น account deletion request แต่ห้ามโพสต์รหัสผ่าน token หรือข้อมูลสุขภาพ เจ้าของบริการจะขอหลักฐานยืนยันบัญชีผ่านช่องทางส่วนตัวก่อนดำเนินการ
